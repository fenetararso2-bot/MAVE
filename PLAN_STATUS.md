- **Phase 3 Query analysis (v0.10.5)**: `app/search/query.py` (stdlib; DB hin qabu) — `analyze(q, lang_hint)` → `QueryInfo(text, normalized, terms, lang, intent)`. `intent` = *akeekkachiisa* qofa (`news|images|videos|tech` ykn `None`): cue jecha tokkoon, mallattoon jabaan tokko qofa yoo qabaate; wal-qixa ykn cue hin jiru → `None`; jechoota wal-nama'an (`python`, `java`, `apple`) cue miti. `lang`: hint UI > jecha Oromoo addaa > jecha Ingliffaa addaa > `None` (qubee Latin Oromoo waan ta'eef ASCII qofaan Ingliffaa hin jedhamu). `GET /api/v1/search` amma `intent` (fuula 1, `type=web` qofa) fi `query_lang` ni deebisa (field dabalataa; Gson/web ni tuffatu — client hin cabu); bu'aan hin jijjiiramu. Web: `intent` yoo jiraate fi tab amma irra jiru irraa adda yoo ta'e "Kutaa kana ilaali: Oduu" link ni agarsiisa (`try_tab`, textContent qofa; CSP hin jijjiiramu). **Cue jechoota Oromoo (`oduu`, `har'a`, `haaraa`, `fakkii`, `suuraa`, `viidiyoo`) fi string `try_tab` (om) ogeessa afaanii irraa mirkaneeffamuu qabu.** Android: hin dabalamne (`SearchResponse` Gson, field haaraa ni tuffatama).
